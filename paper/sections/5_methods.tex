\section{Methods}
\label{sec:methods}
We treated inference of the TSC as a supervised learning problem, with radio and X-ray observations as the input data and the pseudo-TSC label defined in section \ref{sec:sims}.
The generation procedure for the radio and X-ray mocks from simulated data is described in sections \ref{sec:sims} and \ref{sec:fwd}.

We primarily trained a convolutional neural network (CNN), which has shown strong performance on similar astrophysical and cosmological inference problems.
The CNN independently processed each of the three spatial projections of an input cluster using a shared encoder comprising four convolutional blocks, with 32, 64, 128, and 256 output channels.
Each block of the CNN has two convolutional layers, with batch normalization and ReLU (Rectified Linear Unit) nonlinear activations, followed by spatial downsampling.
We then used a global average pooling layer to calculate a 256-dimensional representation of each cluster projection.
The three projection representations are averaged, which makes the prediction independent of projection ordering.
This vector is then passed to a regression head, constructed from a 64-hidden-unit layer with dropout.
In the joint radio and X-ray model, each modality has a separate encoder, with the encodings concatenated before the regression step.

While training, we augmented our set of radio and X-ray projections with random reflections, and $90^\circ$, $180^\circ$, and $270^\circ$ rotations, applied to both observational bands.

For the clean, non-forward-modelled case, we use the 352 snapshot-99 clusters with all three orthogonal projections.
The forward-modelled experiments train on images from snapshots 99 and 91, with evaluation restricted to snapshot 99.
Before training, we normalize the image channels within a fold using the mean and standard deviation of images within that fold.
We apply the same transformation to the validation, test, and observed datasets.

We train models on two types of inputs: idealized pooled-view datasets, in which the three projections of a cluster are combined, and single-view datasets, for which the model is only given one orthogonal projection.
For the latter, we measure the ensemble average performance for five models initialized with five different random seeds.

Observationally forward-modelled data was preprocessed using the procedure described in section \ref{sec:fwd}.
We used AdamW to optimize the CNN for 60 epochs, with an initial learning rate of $3\times 10^{-4}$, weight decay of $10^{-3}$, a cosine learning-rate schedule, and a batch size of 32.
We used a Huber loss function:
\begin{equation}
    L_\delta(r)
    = \begin{cases}
        r^2/2,& |r| \leq \delta,\\
        \delta(|r| - \delta/2),& |r| > \delta,
    \end{cases}
    \qquad \delta = 0.5\,\text{Gyr}
\end{equation}
where $r = \hat T_{\rm pseudo}-T_{\rm pseudo}$ expressed in Gyr.
The loss is quadratic for small residuals and linear beyond the threshold scale of $\delta = 0.5$ Gyr, reducing the influence of large residuals relative to the mean squared error.

The distributional model predicts probabilities for seven classes: 
the first is a threshold reached at or before the smallest sampled window of 0.1 Gyr; 
five are first crossings in intervals $(0.1,0.25]$, $(0.25,0.5]$, $(0.5,1]$, $(1,2]$, and $(2,4]$ Gyr;
and the last is no crossing by 4 Gyr, identified from the score curve.
We train using categorical cross-entropy, and decode the probabilities for point scoring as $\hat T_{\rm pseudo}=\sum_{c=0}^{6}p_c\mu_c$, where $\mu_c$ is the mean label of fitting halos in class $c$ for that fold, with the endpoint representatives fixed at 0.1 Gyr and 4 Gyr.

To evaluate performance, we used five-fold cross validation, with data from each cluster (projections, noise realizations, and available snapshots) always being in the same fold to prevent data leakage.
Within each outer training partition, 15\% of clusters were reserved for training checkpoint selection; we retained the checkpoint with the lowest inner-validation squared error, and excluded the outer test partition from checkpoint selection.
Repeating this procedure for each of the five outer folds produced an out-of-fold (OOF) prediction for each cluster.
Overall, 68\% of clusters were used for training, 12\% were used for inner validation, and 20\% were used for OOF predictive testing.

We measured performance using the coefficient of determination, $R^2$, with overall $R^2$ calculated from the combined OOF predictions.
Our primary experiments were repeated with five random seeds, with comparisons between conditions using shared seeds to reduce noise in comparisons.
We measured scatter across seeds to estimate variation between runs, but this cannot be interpreted as a calibrated uncertainty interval for the TSC.

For paired model comparisons, we use a bootstrap \citep{EfronTibshirani1993}, resampling entire parent halos with replacement 4000 times so that correlated views and realizations of the same halo are drawn together \citep{DavisonHinkley1997}.
We state the 2.5th and 97.5th percentiles of the resulting metric differences as conditional 95\% intervals.
The same sampled halos are used for both compared models.
These confidence intervals condition on fitted runs, and thus do not include uncertainty from retraining on new halo populations.

For an observation with true class $y$ and predicted class probabilities $p_c$, the categorical log score is $-\ln p_y$.
The normalized ranked probability score is
\begin{equation}
    \text{RPS} = \frac{1}{6} \sum_{k=0}^5 \left[ \sum_{c=0}^k p_c - \mathbf{1}(y \leq k) \right]^2
\end{equation}
where $\mathbf{1}$ denotes the indicator function.
Lower values are better for all three scores.

We compare the mean scores on the same held-out observations using paired parent-halo bootstrap intervals, conditional on the fitted models.

To evaluate the increased predictive power from access to raw image data, we compared our CNN model with several scalar prediction baselines.
A five-feature ridge regression model was fit from log(halo mass), log(halo radius), log(integrated emission), mean intensity in the arcsinh-stretched image, and the fraction of pixels with non-zero intensity.
We standardized features over the training data, with ridge regularization strength selected within the training sample.
These comparisons tested whether the raw image data provided extra predictive power over summary statistics of a cluster's scale, emission amplitude, and simple properties of the intensity distribution.

For each radio projection, we threshold the image data at 12 logarithmically-spaced upper-area fractions, $f=0.005$--0.5, using the $(1-f)$ intensity quantile.
At each threshold, we calculate the normalized \todo{normalized how?} perimeter, number of connected components, number of holes, and Euler characteristic, computed as $\chi = N_\text{comp} - N_\text{holes}$.
To decide if pixels are part of the same connected component, we use 8-connectivity for foreground components, and 4-connectivity for background components. \todo{why the difference}?
The perimeter is calculated as the number of foreground-background transitions divided by the number of pixels.
These calculations yield a vector of 48 scalar descriptors, which are supplied to an XGBoost regressor, with projections grouped by cluster during cross-validation, and their predictions averaged for cluster-level scoring.

To characterize X-ray morphology, we caclulate the concentration, centroid variation, and ellipticity.
Let $R$ be half of the image's side length, and denote integrated linear emission within radius $r$ by $F(<r)$.
The concentration is then $F(<0.1R)/F(<R)$.
Centroid variation is calculated as $[\sigma(x_c) + \sigma(y_c)]/R$, evaluated over ten circular apertures spaning $0.1R$ to $R$.
Ellipticity is calculated from the eigenvalues of the intensity-weighted position covariance matrix within $0.5R$.
These features are averaged across projections, then supplied to a ridge regressor.

Several complementary analyses considered the role of mass and emission amplitude.
To test the contribution of explicit amplitude information, one analysis ran shape-normalization \todo{more detail}, with each projection then rescaled to a common integrated emission before applying the intensity arcsinh-stretch.

To remove variation in integrated amplitude from the clean radio maps, we invert the arcsinh-stretch, divide each projection's linear emission by the total emission, and scale by the median of the total emission over all projections.
We then reapplied the arcsinh transform.
Thus, every projection has the same integrated emission, with a retained spatial distribution.
Note that this normalization did not remove correlations between mass, morphology, and luminosity.
We also considered predictive performance within mass bins, and calculated partial-rank correlations between predictions and labels after accounting for halo mass.

For analyses in which we conditioned on cluster mass, we concatenated $\log_{10} (M_\text{500c})$ to the image representation before being fed into the regression head.
To approximate uncertainty associated with weak-lensing masses, we perturbed simulated log-masses with Gaussian noise with widths sampled from the empirical distribution of weak-lensing fractional mass errors.
We used the available fractional uncertainties on $M_\text{200c}$ estimates to approximate uncertainties in the converted $M_\text{500c}$ values.

The idealized optical catalogue contains FoF-member galaxies with stellar particles and intrinsic, dust-free $r$-band absolute magnitude $M_r < -19$.
Richness measures the subset with $M_r < -20$ inside the projected $R_{500}$ of the gas reference center.
The BCG is the brightest member within $0.5 R_{500}$, and the magnitude gap is calculated as the second-brightest minus brightest $r$-band magnitude in that aperture.
The positional features are: the BCG offset from the gas center, its offset from the number-weighted galaxy centroid within $R_{500}$, and the separation of the galaxy centroids within $0.5R_{500}$ and $R_{500}$.
All distances are normalized by the true $R_{500}$.
Simulation membership removes foreground and background interlopers; photometric-redshift errors are not modelled.

The gas reference center is the projected centroid weighted by $m_{\rm gas}\rho_{\rm gas}$, which is a proxy for emission, for gas with $T>3\times10^5$ K and no star formation.
We select gas within a cube of half-width $2R_{500}$ about the \texttt{GroupPos} and within projected $R_{500}$ of that position.

The experiments that have access to all three cluster projections provide a benchmark in which several views of the same cluster are available, which can be compared with the model performance on the realistic case individual observed images from a single viewing direction.
The latter can be interpreted alongside the corresponding observationally forward-modelled tests.
Because the observed clusters lack independent pseudo-TSC labels, agreement between radio and X-ray predictions provides a consistency check rather than a direct accuracy measurement.

We rank the two prediction vectors and the nuisance variable once, and regress each ranked prediction on an intercept and the ranked nuisance variable.
Their residual correlation is the partial-rank statistic.
For the Freedman--Lane test, we permute the residuals of one prediction, add back its fitted nuisance component, and recompute the partial statistic after nuisance regression, without reranking the permuted values.
We use a two-sided permutation comparison.
Note the resulting inference is conditional on the fitted nuisance model
and its residual-exchangeability assumptions.
