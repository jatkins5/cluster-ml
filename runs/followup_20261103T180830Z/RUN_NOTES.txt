Offset interpretation
  Positive offsets mean radio predicts an older pseudo-TSC than X-rays.
  Use held-out single-view predictions averaged across seeds. Resampling is
  by parent halo, keeping snapshots, projections, and realizations together.
  Conditional mean summaries give equal weight to each contributing parent.
  Observed matching uses fixed calipers: 0.2 dex in mass, 0.015 in redshift,
  factor 2 in X-ray exposure; report four hypothetical true-age bins rather
  than treating a predicted observed age as truth. Require eight parents.
  The observed comparison uses the same five models (one fold per seed) as
  each simulated held-out halo, although headline real predictions average
  all 25 fold/seed models. This is a bias diagnostic, not age calibration.

Relic pilot interpretation
  Six halos selected using merger history only: exactly one mass-ratio>=0.1
  event in the last 2 Gyr, collision age 0.15-1.5 Gyr, two per age bin, seed42.
  Candidate event ages use continuous T_coll. The legacy per-halo TSC label
  differs for some events by up to one snapshot cadence; it is not used as
  the pilot clock. Target indices are checked against the TNG-Cluster list.
  Regenerate ONLY selected cutouts at 1.4 GHz with the current synchrotron
  prescription and the existing n_H<=1e-4 selection. Existing radio files
  are untouched. Use 50 kpc connected voxels; retry 25 kpc for a single
  detected relic. Apply volume, bright-cell-cleaning, size, Mach, luminosity,
  and opposite-side selection for inspection; axis alignment is diagnostic,
  never used to select a pair. Inspect snapshots 91 and 99 and competing
  events. All associations remain explicitly unverified. No population
  slope or timing accuracy is inferred from six selected halos.
  Differences in radio prescription, gas cuts, and temporal coverage mean
  this is a feasibility pilot, not a completed Lee et al. replication.
  References: https://arxiv.org/html/2510.21632v1
              https://www.tng-project.org/data/cluster/
